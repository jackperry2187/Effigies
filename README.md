**Effigies** is a mod that adds powerful mob spawning prevention options to the game.  

## Version Support

Effigies supports multiple Minecraft versions and mod loaders:

| Loader | Minecraft Versions |
|--------|-------------------|
| **Fabric** | 1.21.11+ |
| **NeoForge** | 1.21.11+ |

## Features  
  
- Adds 7 new Pikes (one for each spear variant) that prevent mob spawning within a radius based on their variant
    - Refer to the **Pike Table** for specifics about the radius' and recipes
- Right clicking a Pike will place it, and right clicking it again with a mob head will activate it, preventing spawns within its radius
- Shift+Right-Clicking a Pike that already has a head on it will drop the head, and breaking it will drop both the Pike and the head 

## Pike Table

| Tier | Recipe | Area of Effect |
| ---- | ------ | -------------- | 
| Wooden | 1 Wooden Spear + 2 Sticks | 1 Chunk (the chunk it's in) |
| Stone | 1 Stone Spear + 2 Sticks | 1 Chunk + 1 Radius (the chunk it's in + all 8 surrounding chunks)
| Copper | 1 Copper Spear + 2 Sticks | 1 Chunk + 2 Radius |
| Iron | 1 Iron Spear + 2 Sticks | 1 Chunk + 4 Radius |
| Gold | 1 Gold Spear + 2 Sticks | 1 Chunk + 6 Radius |
| Diamond | 1 Diamond Spear + 2 Sticks | 1 Chunk + 8 Radius |
| Netherite | 1 Netherite Spear + 2 Sticks | 1 Chunk + 16 Radius |
